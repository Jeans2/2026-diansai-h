## 1. 项目目标与硬件分工

- 赛题：H题车载平衡滚球运动控制系统。
- K230庐山派：摄像头识别钢球位置、触摸菜单、Wi-Fi RTSP图传、通过串口发送钢球位置和模式命令。

- 另一块天猛星单独负责红外循迹，不与钢球控制天猛星通信。
- 摆杆为PPR管，钢球位置范围约为正负12 cm。

## 3. K230当前启动流程

当前是分步启动版，不是点击菜单后立刻启动电机：

1. 在菜单选择Mode 3/4/5/6。
2. 点击`OPEN RTSP`。
3. 摄像头、识别和RTSP开始运行，但此时不发送模式启动命令。
4. 在电脑/VLC连接RTSP并开始录像。
5. 点击K230画面中的`START TASK`。
6. 连续得到3个有效钢球位置后，K230才发送`MODE,3/4/5/6`。

Mode 1和Mode 2只进行原始画面RTSP图传。Mode 3/4/5/6同时进行识别和控制，但RTSP发送的仍是无标记原始画面，本地K230屏幕才显示识别框和文字。

## 5. K230当前钢球识别算法

当前不使用YOLO，使用OpenCV霍夫圆：

```text
RGB图像
→ 固定管道ROI
→ 灰度化
→ 7×7高斯滤波，sigma=1.5
→ 单次HoughCircles
→ 候选圆筛选
→ 分段标定换算厘米位置
```

当前参数：

```python
HOUGH_DP = 1.2
HOUGH_MIN_DISTANCE = 30
HOUGH_CANNY_THRESHOLD = 70
HOUGH_ACCUMULATOR_THRESHOLD = 18
FIXED_RADIUS = 17
MIN_RADIUS = 10
MAX_RADIUS = 26
TRACK_X_COST_DIVISOR = 8
ROI_CIRCLE_EDGE_MARGIN = 2
```

最新识别变更：

- 半径已经由`12～23 px`放宽为q3代码使用的`10～26 px`。
- 光照处理已经改为q3方式：灰度化、高斯滤波后直接用`70/18`检测一次。
- 已暂时关闭`equalizeHist()`直方图均衡和第二次备用检测。
- ROI上下边缘残缺圆过滤必须保留，用户曾说“算了，保留”。
- 候选评分仍综合管道中线距离、半径与17的差值以及上一帧横向位置。
- 连续丢失3次才发送`NOBALL`；本地画面最多保持旧框2帧。

当前ROI与标定（除非用户明确要求，否则不要修改）：

```python
ROI_CENTER_Y_NORM = 0.405
ROI_HALF_HEIGHT = 38
CALIBRATION_X_NEG10 = 17.0
CALIBRATION_X_ZERO = 407.0
CALIBRATION_X_POS10 = 795.0
```

位置换算使用左右分段线性映射：`x=17 → -10 cm`、`x=407 → 0 cm`、`x=795 → +10 cm`。

## 6. K230与天猛星串口

当前K230菜单程序使用UART3：

```text
K230 GPIO50 / TX → 天猛星 PB7 / K230_UART RX
K230 GPIO51 / RX ← 天猛星 PB6 / K230_UART TX
K230 GND          ↔ 天猛星 GND
波特率：115200，8N1
发送周期：20 ms（约50 Hz）
```

庐山派GH1.25-4P UART3插座标记为`VCC/R/T/G`时：

- `T`接天猛星PB7（RX）。
- `R`接天猛星PB6（TX）。
- `G`接天猛星GND。
- 两块板分别供电时，通常不要连接`VCC`，只交叉TX/RX并共地。

主要协议：

```text
BALL,500      小球位置 +5.00 cm
BALL,-530     小球位置 -5.30 cm
NOBALL        视觉确认丢球
MODE,3        启动第三问
MODE,4        启动第四问
MODE,5        启动第五问
TARGET,300    设置Mode 6目标 +3.00 cm
MODE,6        启动第六问
```

## 7. Mode 3当前版本

Mode 3是独立状态机，当前流程：

```text
启动前要求钢球位于0点±1 cm
→ PID目标 +5.00 cm
→ 保持/计时1.0秒后自动切换
→ PID目标 -5.30 cm
→ 在负目标处稳定
→ 稳定保持3秒
→ 步进电机回到机械水平零点
```

总任务时间限制为5秒。

当前参数：

```text
Kp = 200
Ki = 50
Kd = 3500
电机位置限幅 = ±900步
位置死区 = ±0.15 cm
离开稳定区重新启动阈值 = ±0.25 cm
速度死区 = 0.02 cm/控制周期
稳定判定 = 连续20次
积分启用误差范围 = ±2.00 cm
积分限幅 = 30000
电机目标每次最大变化 = 300步
电机目标更新死区 = 20步
步进频率 = 3500 Hz
丢球计数上限 = 20次
```

Mode 3当前负目标必须是`-530`，不要误回退到`-500`。

## 8. Mode 4、Mode 5、Mode 6当前关系

三者共用`mode4_ball_balance.c`控制器。

### Mode 4

- 目标固定为0 cm。
- 普通精度配置。
- 用于直线行驶中稳球。

### Mode 5

- 当前与Mode 4完全相同。
- 目标固定为0 cm。
- 后续可以根据整圈实测单独分离参数，目前还没有分离。

### Mode 6

- 使用K230触摸屏移动目标线，目标范围约为正负10～12 cm。
- 使用高精度配置。

## 9. 步进电机与D36A接线

天猛星当前SysConfig：

```text
PA17 → D36A STEP/PUL
PA14 → D36A DIR
PA15 → D36A EN
GND  ↔ D36A信号GND
PB0  → 最小限位开关（当前可不安装，内部上拉）
PB1  → 最大限位开关（当前可不安装，内部上拉）
```

D36A接步进电机和电机电源时按驱动器端子标识连接。电机电源不要从K230或天猛星GPIO供电，控制侧必须共地。

当前方向约定：

```text
负步数：机构向上
正步数：机构向下
```

已测机械数据：

```text
MOVE,1000,1000：约移动2.53～2.62 mm
MOVE,2000,1000：约移动5.22～5.24 mm
```

机械水平位置已经标定为步进位置0。
