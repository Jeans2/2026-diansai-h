# K230 Mode4 自动识别控制

这是一份独立的精简程序，不会修改现有 `k230/main.py` 或触摸菜单。

## 功能

- OpenCV圆形检测钢球
- 屏幕显示ROI、球位置、帧率和Mode4状态
- 连续识别到3个有效位置后，自动向天猛星发送一次 `MODE,4`
- 随后每20ms发送 `BALL,位置x100`
- 丢失小球时发送 `NOBALL`
- 普通检测失败后，自动使用直方图均衡和备用霍夫参数重试
- 使用上一帧球心辅助选择候选圆，降低反光点误识别概率
- 连续丢失3次才发送 `NOBALL`，过滤偶发单帧丢失
- ROI缩小并向上微调，排除管道下方圆形零件
- 检测圆必须完整位于ROI内部，过滤边缘处的半圆误检
- 显示画面短暂丢失时保持最近结果2帧，避免识别框频闪；UART不发送伪造位置
- 不包含触摸菜单、Wi-Fi、RTSP和YOLO

## 光照设置

建议使用带柔光罩的固定白色LED照明，避免灯珠直接照射钢球。

如果最终比赛照明固定，可在 `main.py` 顶部设置：

```python
USE_MANUAL_EXPOSURE = True
MANUAL_EXPOSURE_US = 10000
```

曝光建议从 `8000` 到 `12000` 微秒逐步测试。默认不锁定曝光，避免未经测试时画面过亮或过暗。

## 脱机运行

把本目录中的 `main.py` 复制到K230 SD卡根目录并命名为 `main.py`。上电后程序会自动运行。

## 串口接线

| K230 GH1.25 UART3 | 天猛星 |
|---|---|
| T / GPIO50 | K230串口RX |
| R / GPIO51 | K230串口TX（当前程序不读取回复，可暂不接） |
| G | GND |
| VCC | 不接 |

串口参数为 `115200, 8N1`。

天猛星调试Type-C继续连接电脑COM7，Codex可通过周期发送 `STATUS` 采集 `ball`、`pos`、`u`、`vel`、`kp`、`ki` 和 `kd`。

如需自动进入Mode5，只把程序顶部的：

```python
AUTO_MODE = 4
```

改成：

```python
AUTO_MODE = 5
```
