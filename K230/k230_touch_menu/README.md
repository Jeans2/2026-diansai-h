# K230 庐山派触摸菜单与图传

板载入口是 `main.py`，`touch_menu_test.py` 与它内容相同，便于在 CanMV IDE 中手动测试。

## 已实现模式

- 模式1：原始 H.264/RTSP 图传。
- 模式2：原始 H.264/RTSP 图传；循迹由另一块天猛星独立完成。
- 模式3：钢球圆检测、UART位置发送、启动天猛星模式3，同时进行原始图传。
- 模式4：钢球圆检测、UART位置发送、启动天猛星模式4，同时进行原始图传。
- 模式5：钢球圆检测、UART位置发送、启动天猛星模式5；天猛星暂时复用模式4参数，同时进行原始图传。
- 模式6：菜单入口保留，控制功能尚未接入。

模式3/4/5使用两个相机输出通道：

- 通道0：640x360 YUV原始画面，直接送H.264编码器和RTSP。
- 通道2：800x480 RGB画面，用于圆检测、本机屏幕ROI和位置标记。

所以VLC和录制文件中只有原始摄像头画面，不会出现ROI、圆框、刻度线或位置文字；这些识别标记只显示在K230本机屏幕上。

## 使用

1. 把本目录的 `main.py` 放到K230 SD卡根目录。
2. 上电后在触摸屏选择模式，再点 `START`。
3. 手机或电脑连接热点 `K230-Video`，密码 `12345678`。
4. VLC打开 `rtsp://192.168.4.1:8554/live`。
5. 模式运行期间不热切换；复位K230后返回菜单，并让电脑端录像程序结束保存。

模式3/4/5的控制串口仍为UART3：GPIO50是K230 TX，GPIO51是K230 RX，波特率115200。K230会先发送第一帧有效 `BALL,<位置x100>`，再发送一次 `MODE,3`、`MODE,4` 或 `MODE,5`。
